Быстрый, стильный и безопасный браузер

Nebula Browser — современный веб-браузер на базе Chromium с интеграцией Chrome Web Store, Discord Rich Presence, менеджером паролей и кастомизацией интерфейса.

Скачать для Windows (x64) Все релизы
Поддерживает Windows 10 / Windows 11 (64-bit) • Бесплатно и с открытым исходным кодом

Создан для максимального комфорта

Все необходимые функции уже встроены и работают прямо из коробки

Discord Rich Presence

Транслирует вашу активность и посещаемый сайт (YouTube, Twitch, GitHub и др.) с таймером проведенного времени прямо в профиль Discord.

Chrome Web Store

Прямая установка расширений из официального интернет-магазина Chrome в 1 клик — VPN, AdBlock, переводчики и инструменты разработчика.

Менеджер паролей

Безопасное хранилище на базе SQLite с аппаратным шифрованием Windows DPAPI, умным автозаполнением, генератором и экспортом в CSV.

Блокировка рекламы

Встроенный фильтр сетевых запросов блокирует навязчивые баннеры, трекеры и шпионские скрипты без нагрузки на процессор.

Космические темы

Выбирайте из авторских космических градиентов или установите любое собственное фото с компьютера на начальный экран.

Drag & Drop и вкладки

Свободное перетаскивание вкладок, закладок и плиток быстрого доступа, открытие ссылок колесиком мыши в новой вкладке.
