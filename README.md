## 🚀 О проекте

**Nebula Browser** — современный веб-браузер для Windows с акцентом на приватность, скорость работы и потрясающий темный космический интерфейс. Браузер объединяет мощь движка Chromium с кастомным легковесным интерфейсом, встроенным блокировщиком рекламы, локальным хранилищем SQLite и поддержкой расширений Chrome Web Store.

---

## ✨ Основные возможности

### 🧩 Поддержка расширений Chrome Web Store
- Установка расширений напрямую из официального [Интернет-магазина Chrome](https://chromewebstore.google.com/) в один клик.
- Поддержка расширений Manifest V2 и Manifest V3 (uBlock Origin, VeePN, SteamDB и многих других).
- Нативные бесрамочные всплывающие окна (popups) прямо под панелью инструментов с автозакрытием при клике вне окна или по клавише `Escape`.
- Автоматический патчинг Service Worker и полифилы современных Chrome Extension API (`chrome.privacy`, `chrome.action`, `chrome.proxy`, `chrome.storage.session`).

### 🛡 Встроенный AdBlock
- Блокировка рекламы, баннеров, трекеров и систем слежения «из коробки».
- Управление блокировкой в один клик прямо из верхней панели инструментов.
- Значительное ускорение загрузки тяжелых страниц без расхода оперативной памяти.

### 🔑 Продвинутый менеджер паролей
- **Безопасность**: все пароли хранятся локально в базе данных **SQLite** и защищены системным шифрованием **Windows DPAPI** (`safeStorage`).
- **Скроллинг и интерфейс**: аккуратный список с фавиконками сайтов, скрытием/раскрытием паролей и быстрым копированием логина и пароля в один клик.
- **Генератор надежных паролей**: создание стойких 16-значных паролей прямо в форме добавления.
- **Импорт CSV**: удобный перенос сохраненных паролей из Google Chrome, Яндекс.Браузера, Opera и Microsoft Edge.
- **Живой поиск**: мгновенная фильтрация по сайту или логину.

### ⚡ Производительность и архитектура
- Полностью модульная архитектура (`tabs.js`, `passwords.js`, `bookmarks.js`, `history.js`, `downloads.js`, `extensions.js`, `db.js`).
- Все данные (история, закладки, пароли, экспресс-панель) надежно хранятся в легковесной базе SQLite (`sql.js`).
- Минимальное потребление памяти и моментальный отклик интерфейса.

### 📥 Менеджер загрузок
- Отслеживание скорости загрузки, процентного выполнения и расчетного оставшегося времени (ETA).
- Всплывающие уведомления (toasts) о начале и успешном завершении скачивания.
- Быстрый доступ к истории файлов и открытие папки с файлом.

### 🎨 Кастомизация и экспресс-панель (Speed Dial)
- Начальная страница с настраиваемыми карточками быстрого доступа к любимым сайтам.
- Выбор поисковой системы по умолчанию (Google, Яндекс, DuckDuckGo, Bing, Ecosia).
- Панель визуальных закладок со стильными иконками.

## 📥 Установка

1. Перейдите на страницу [последнего релиза](https://github.com/h6rnyxxx/nebula-browser/releases/latest).
2. Скачайте файл установщика `Nebula_Browser_Setup_<версия>.exe`.
3. Запустите установщик. Браузер автоматически установится и создаст ярлыки на рабочем столе и в меню «Пуск».
4. Браузер оснащен системой фонового автообновления — при выходе новых версий они скачиваются и устанавливаются автоматически.

## 🛠 Сборка из исходников

### Требования
- **Node.js**: v18+ или v20+
- **ОС**: Windows 10 / 11 (x64)

### Инструкция

```bash
# Клонируйте репозиторий
git clone https://github.com/h6rnyxxx/nebula-browser.git
cd nebula-browser

# Установите зависимости
npm install

# Запуск в режиме разработки
npm start

# Сборка установочного пакета (.exe)
npm run build
```

## 🔒 Безопасность и конфиденциальность

- Браузер не передает и не сохраняет персональные данные пользователей на сторонних серверах.
- Все учетные данные шифруются локально с помощью криптографических интерфейсов операционной системы.
- Исходный код проекта открыт для аудита сообществом.
